# B Scope 实现说明

## 已完成能力

- 微信小程序登录：用户端通过 `uni.login` 获取 code，后端调用 WeChat `code2Session` 完成登录。
- 学号实名：通过本地权威学籍名单进行精确匹配，实名成功后用户状态更新为 `VERIFIED`。
- 动态分类：用户端首页和发布页、后台商品页和分类管理页全部改为从后端分类 API 读取。
- 面交点选择：发布商品时可通过腾讯地图搜索面交点，商品详情页展示面交点信息。
- 收藏与评论：商品详情页支持收藏、查看评论、发表评论，后端维护相应计数。
- 订单闭环增强：支持“我买到的”“我卖出的”，完成订单后买卖双方可分别评价，后端更新评分和信用分。
- 轻量推荐：基于收藏、评论、下单行为和分类偏好生成推荐列表，首页显示 `Recommended` 区块。
- 后台治理视图：新增实名状态页面和评论管理页面。

## 真实接入与模拟边界

- 真实接入：
  - 微信小程序登录
  - 腾讯地图 WebService 搜索与逆解析
- 模拟但可替换：
  - 学校实名系统使用本地 `biz_student_roster` 作为权威数据源

这意味着当前项目已经具备完整业务流程，但“学校官方接口”仍然是后续可替换的依赖项。

## 数据初始化

- `backend/src/main/resources/database.sql`：数据库结构基线
- `backend/src/main/resources/data.sql`：验收演示数据，覆盖分类、实名名单、演示账号、商品、订单、聊天、收藏、评论、评价和推荐行为

建议在目标数据库已创建的前提下手工执行上述 SQL，而不是把它们作为每次启动自动覆盖的数据脚本。

如需调整演示数据，修改并执行：

```powershell
python tools\generate_demo_data.py
```
