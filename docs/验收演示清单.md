## 第五部分：技术亮点总结（口头说明）

演示完功能后，可以向老师总结以下技术亮点：

### 架构设计
- **前后端分离**：Spring Boot 后端 + Vue3 Web 端 + Vue3 Admin 端 + uni-app 小程序端
- **三端共用同一套 RESTful API**，数据完全一致
- **JWT Token 认证**：统一的身份验证机制，Token 存储在 Redis 中，72 小时过期

### 前端技术
- **Web 端**：Vue3 + Vite + GSAP 动画 + 响应式布局
- **Admin 端**：Vue3 + Element Plus + ECharts 图表
- **小程序端**：uni-app + uView Plus 组件库，一套代码多端运行
- **动效设计**：首页 stagger 入场动画、Header 毛玻璃收缩、详情页 Reveal 动画

### 后端技术
- **Spring Boot** + MyBatis-Plus + Redis 缓存
- **WebSocket** 实时聊天
- **AI 智能推荐**：接入 DeepSeek 大模型，自然语言找货
- **腾讯地图 API**：地理位置选择与逆地理编码
- **文件上传**：支持多图上传，最大 10MB

### 数据设计
- 12 个商品分类全覆盖
- 商品支持 1-4 张图片，图片与描述严格匹配
- 5 种商品状态完整流转：待审核 → 在售 → 已下架/已驳回/已售出
- 边界场景覆盖：空描述、空地点、极端价格
