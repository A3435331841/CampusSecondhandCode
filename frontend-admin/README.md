# 校园二手交易管理端

基于 Vue 3、Vite、Element Plus 和 ECharts 的后台管理端，用于管理员审核商品、管理用户、维护分类、查看评论和数据看板。

## 启动

```powershell
npm install
npm run dev
```

默认访问地址通常为：

```text
http://localhost:5173
```

## 演示账号

```text
admin / 123456
```

管理端登录页会拦截非管理员账号；普通用户即使能登录后端，也不会进入后台界面。

## 构建

```powershell
npm run build
```
